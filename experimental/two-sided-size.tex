\noindent Columns use $H=\max_i r_i$, $\max(R_L,R_R)$, $(R_L+R_R)/2$, and $\sqrt{R_LR_R}$.
The maximum reproduces the previous rule. $R$ is an input to native delimiter selection, not the exact rendered half-height.
This is an experimental heuristic.}
